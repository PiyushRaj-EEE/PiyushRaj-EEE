### EV Powertrain Simulator

An engineering project focused on understanding and simulating electric vehicle powertrain behaviour using MATLAB and Simulink.

**Areas of focus:**

* 🔋 Battery modelling and State of Charge (SOC) estimation.
* ⚙️ Electric motor and vehicle dynamics.
